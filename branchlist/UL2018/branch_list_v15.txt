# NanoAODv15 branch list for SSBNanoAODANCode.
#
# The dataType/varType columns are now only a fallback hint - Analysis::InitBranches()
# auto-detects the real type and single/vector structure from the TChain itself, so
# they no longer need to be exact. What DOES need to be exact is the branch NAME,
# since a few branches were renamed (not just retyped) going from v9 to v15:
#   fixedGridRhoFastjetAll -> Rho_fixedGridRhoFastjetAll
#   MET_pt / MET_phi       -> PFMET_pt / PFMET_phi   (Analysis.cpp tries both names)
#   Electron_mvaFall17V2Iso*     -> Electron_mvaIso*
#   Electron_mvaFall17V2noIso*   -> Electron_mvaNoIso*
#
# Removed with no direct successor (see conversion notes):
#   Jet_jetId   -> gone. Replaced by PassJetIdTight()/PassJetIdTightLepVeto() in
#                  Analysis.cpp, computed from the energy-fraction branches below.
#   Jet_puId    -> gone (only the continuous Jet_puIdDisc remains, no correctionlib
#                  SF yet). Analysis.cpp auto-disables PU-jet-ID if this line is absent.
#   Jet_btagCSVV2 / Jet_btagDeepB / Jet_btagDeepCvB / Jet_btagDeepCvL -> gone (DeepCSV
#                  retired). Use Jet_btagDeepFlavB/CvB/CvL/QG (DeepJet) or the new
#                  Jet_btagPNet*/Jet_btagUParTAK4* taggers. Make sure your v15 configs
#                  set Jet_btag = deepJet (or a PNet/UParT WP you've added support for).
#   Muon_mvaTTH / Muon_mvaId / Muon_mvaLowPtId -> gone, no direct successor used here.
